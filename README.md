# SplitSpammer

## About

A planned LiveSplit component that auto splits GTA San Andreas (PC version 1.0). It reads the game's memory and splits LiveSplit's timer, with a settings tree that you can collapse and expand, so the several hundred split options stay manageable.

It replaces an ASL auto splitter script that has outgrown a single ASL file.

## Status

Not usable yet: the component loads in LiveSplit and shows the game's status and a tree of settings (so far only the group headers), but it does not split yet, and there is no release. The planned work is listed in [docs/TODO.md](docs/TODO.md).
