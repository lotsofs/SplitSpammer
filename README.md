# SplitSpammer

## About

A planned LiveSplit component that auto splits GTA San Andreas (PC version 1.0). It reads the game's memory and splits LiveSplit's timer, with a settings tree that you can collapse and expand, so the several hundred split options stay manageable.

It replaces `GTASA.asl` from [livesplit-asl](https://github.com/lotsofs/livesplit-asl), which has outgrown a single ASL script.

## Status
