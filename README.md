# SplitSpammer

## About

A planned LiveSplit component that auto splits GTA San Andreas (PC version 1.0). It reads the game's memory and splits LiveSplit's timer, with a settings tree that you can collapse and expand, so the several hundred split options stay manageable.

It replaces an ASL auto splitter script that has outgrown a single ASL file.

## Status

Not usable yet: the component loads in LiveSplit, shows the game's status and a tree of settings, can split on the first two missions, In the Beginning (off by default) and Big Smoke (its pass on by default), and starts and resets the timer when a new game starts. Nothing else splits yet, and there is no release. The planned work is listed in [docs/TODO.md](docs/TODO.md).
